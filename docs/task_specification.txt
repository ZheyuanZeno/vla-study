## 六、Phase 3：实现 Visual Masking

需要在模型接收的外部摄像头图像中添加遮挡。

所有遮挡必须在图像 resize 之后、normalization 之前完成。

不能只修改录像画面。

不能修改模拟器的真实物理场景。

不能对腕部摄像头、机器人状态或语言指令添加遮挡。

实验一共七种条件：

| Condition | Mask location | Severity |
|---|---|---|
| Baseline | None | None |
| T1 | Target region | Small |
| T2 | Target region | Medium |
| T3 | Target region | Large |
| B1 | Background | Small |
| B2 | Background | Medium |
| B3 | Background | Large |

遮挡参数：

- 形状：正方形
- 颜色：RGB (128, 128, 128)
- 不透明度：100%
- 边界：硬边界，不进行 blending
- 在同一 episode 内位置和尺寸固定
- 在每次 policy observation 中持续应用

Target region 定义为机器人需要将物体放入或放置到的固定目标区域。

不使用任意物体或机器人本体作为替代。

遮挡大小需要覆盖目标区域可见像素的至少：

- Small：25%
- Medium：50%
- Large：75%

优先尝试获取模拟器 segmentation，确保与实际摄像头视角和图像尺寸对应，并通过 nearest-neighbour interpolation 调整分割图。

对于每个目标区域，基于 reset 后可见目标像素质心，计算满足对应覆盖率的最小整数边长正方形。

如果无法可靠取得 segmentation，可以实现手动标注初始帧 polygon 的备用方案。该方案必须保留真实图像依据和可视化验证，不能随意猜测目标坐标。正式实验前还需要由另一位研究者独立检查。

Background mask：

- 使用与对应 T 条件完全相同的宽高和颜色
- 位置选择在任务无关背景区域
- 每个任务的背景 anchor 在 Pilot 阶段确定并冻结
- 检查不会在 reset 时覆盖目标、操作物体、机器人或其他任务相关地标
- 检查三个大小都在图像边界内

需要保存：

- 原始 RGB 图像
- 实际进入 policy 的 masked RGB 图像
- mask bounding box
- mask pixel area
- target coverage
- background anchor
- 相应任务和初始状态的 ID

增加可视化检查和自动化单元测试，验证 T/B 成对的几何尺寸完全相等，且零面积 Mask 不改变输入。

Phase 3 验收标准：

同一个真实 LIBERO 初始状态，可以完成一次 T1 和 B1 的完整机器人 rollout，并保存正确遮挡的实际模型输入。

## 七、Phase 4：小规模配对 Pilot

在确认 Masking 功能可靠后，实现完整七条件配对运行。

配对单位是一个 LIBERO 任务的同一个初始状态。

同一初始状态需要分别运行：

Baseline、T1、T2、T3、B1、B2、B3。

要求：

- 七种条件使用相同初始状态
- 固定 checkpoint
- 固定任务指令
- 固定控制模式与 horizon
- 条件之间 reset simulator
- 清空模型 action queues 和 policy caches
- 条件顺序根据记录的随机种子随机化
- 图像 Mask 仅影响对应的 policy observation
- 每次 rollout 独立记录真实结果

首先只测试 1 个任务 × 1 个初始状态 × 7 个条件。

只有这 7 次全部完成后，再扩展到多个状态。

检查 LIBERO 现有初始状态集合：

- 有多少独立初始状态？
- 是否能够准确加载同一个状态？
- 是否能够确保同一个初始状态配对？
- 是否可以合法、可靠地生成更多初始状态？
- 不同初始状态是否真的不同？

不要将完全相同的确定性执行重复多次，视为新的独立实验样本。

对候选任务的正式筛选，应按照 Research Plan 中规定的 LIBERO-Spatial 和 LIBERO-Object 的任务 ID 顺序进行。

任务必须具有固定的 placement destination、可见目标及合法背景 Mask。

Baseline 的试验性筛选标准为每个任务 20 个未遮挡 episode 中至少成功 10 次。最终选择前四个满足条件的任务，记录排除原因。

不要根据哪个任务的遮挡效果更显著来挑选任务。

Pilot 结果不能混入正式实验统计。

## 九、Phase 5：统计分析

分析模块单独实现，和模拟器执行解耦。

主要指标：

Success Rate

以及每个 mask-size level 的：

Gap = SR_background - SR_target

正值意味着目标遮挡带来的成功率下降更严重。

四个任务应分别计算，再对四个任务的差值取等权平均。

按照 Research Plan，使用 5,000 次 paired bootstrap。

同一个 initial-state block 的七种条件必须作为整体重采样，不能把七次 rollout 当成独立样本。

在每个任务内部进行 bootstrap，再对四个任务等权汇总。

输出：

- 每种条件的 Success Rate
- 每个任务的 T/B Gap
- 四任务平均 Gap
- pointwise 95% bootstrap percentile interval
- Large Gap - Small Gap
- Mask severity 对成功率的影响图
- 四个任务的单独结果图
- Baseline 与遮挡实验的比较图

统计代码可以先用明确标记为 synthetic 的测试数据开发，但最终报告只能使用真实 rollout 结果。
