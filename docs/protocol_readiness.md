## 状态与统计范围

新状态池来自同一 LIBERO BDDL 的 seeded reset，不是官方发布的原生固定初始状态列表。状态向量不包含全部固定设施变换，因此使用 seed、动态状态、设施快照和物体位姿共同验证。去重距离不等于数学上证明独立，采样独立性仍是统计假设。详见 [新池证据](generated_state_pools.md)。

首选 100 状态方案为 4×100×7=2800 条；备选取同一新池前 50 状态，为 1400 条。两者均与原生筛选/开发姿态及保留 Pilot ID 100 分离。原 configs/formal50_protocol.json 是旧代码下复用原生池的历史方案，不再作为当前首选入口。

正式分析只接收批准协议下的完整七条件 block，保留任务失败和 timeout；技术失败保留日志后在同单位重试。任务内整块 bootstrap 5000 次，再对四任务等权平均。当前没有正式数据，不输出正式置信区间或研究结论。
